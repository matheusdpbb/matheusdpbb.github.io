Política de privacidade

Atualizada em 15 de outubro de 2026.

O que é

vds-workspace é uma ferramenta pessoal, usada apenas pelo dono da conta Google que a autoriza. Não há outros usuários.

Dados acessados

Com a autorização do dono, a ferramenta acessa Gmail, Google Agenda, Google Drive, Planilhas e Documentos da própria conta, para ler, organizar e criar conteúdo a pedido dele.

Como os dados são usados e guardados

  • Os dados são processados apenas no servidor privado do dono e usados só para as tarefas que ele pede.
  • Nada é vendido, compartilhado com terceiros ou usado para publicidade.
  • As credenciais ficam criptografadas nesse servidor.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.
